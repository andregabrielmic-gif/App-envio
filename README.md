# 📦 Sistema de Envio de Equipamentos com Checklist

## 📌 Sobre o projeto
Aplicativo desenvolvido para controle e envio de equipamentos (como computadores) para o setor de TI, garantindo que todas as informações importantes sejam registradas antes do envio.

O sistema foi criado para evitar falhas de comunicação, padronizar processos e facilitar a análise dos equipamentos recebidos pela equipe técnica.

---

## 🌐 Aplicação em funcionamento

Você pode acessar o sistema online através do link abaixo:

🔗 https://andregabriel.pythonanywhere.com/

> Obs: Projeto hospedado para demonstração. Algumas funcionalidades podem estar limitadas.

## 🚀 Funcionalidades

- 📋 Checklist pré-definido antes do envio
- 🖥 Registro de informações do equipamento
- 📸 Upload de fotos do equipamento
- ✅ Perguntas padronizadas, como:
  - Está ligando?
  - Está dando imagem?
  - Possui avarias visíveis?
- 📝 Observações adicionais
- 📦 Controle de envio para o setor de TI

---

## 💡 Problema que resolve

Antes do sistema, os equipamentos eram enviados sem padrão de informações, o que gerava:
- Falta de dados importantes
- Retrabalho para a equipe de TI
- Dificuldade em identificar problemas

Com o sistema, todas as informações vão organizadas junto com o equipamento, facilitando o diagnóstico e agilizando o processo.

---

## 🛠 Tecnologias utilizadas

- Python
- Flask
- SQLite - Banco de dados leve (SQLite) utilizado para simplicidade e fácil execução local, com possibilidade de migração para bancos mais robustos como PostgreSQL ou MySQL.
- SQLAlchemy
- ReportLab (geração de PDF)
